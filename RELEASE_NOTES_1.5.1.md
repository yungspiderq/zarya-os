# ЗАРЯ OS 1.5.1 — Исправление магазина комплектующих

Небольшое обновление удобства использования.

## Исправлено
- Магазин комплектующих теперь прокручивается колёсиком мыши, тачпадом и с помощью полосы прокрутки.
- Все модели процессоров, видеокарт, оперативной памяти, материнских плат, блоков питания и накопителей доступны даже в небольшом окне.
- Вкладки категорий закреплены в верхней части магазина при прокрутке.
- При фокусе на магазине работают клавиши прокрутки, включая Page Down и стрелки.
- Обновлены версии CSS и JS в ссылках, чтобы не загружались устаревшие файлы из кэша браузера.

## Совместимость
Все покупки, установленные комплектующие, инвентарь, контракты и сохранения версии 1.5.0 сохраняются.

Это техническое исправление без изменения игровой экономики.

## Запуск
Скачай `zarya-os-1.5.1.zip`, распакуй и открой `index.html`.
Онлайн: https://yungspiderq.github.io/zarya-os/?v=1.5.1
