# ЗАРЯ OS 2.2.1 «Security Overhaul»

Обновление по результатам независимой проверки античита. Локальную контрольную сумму Zarya OS смогли воспроизвести вне браузера, поэтому вместо очередной замены алгоритма мы добавили **рабочий прототип серверного кошелька**.

## Что появилось

### Проверка безопасности
Новое приложение Zarya OS отдельно показывает две суммы:
- **Локальные ₡** основной игры — по-прежнему не защищены от игрока, который управляет кодом в браузере.
- **Подтверждённые ₡** — их хранит отдельный Node.js-сервер. Он сам проверяет отчёты по восьми вымышленным сетевым расследованиям и **сам определяет сумму награды**, независимо от параметров клиентского запроса.

У подтверждённого кошелька есть **история событий**, отдельный анонимный cookie-сеанс и серверный магазин трёх сертификатов. Цены фиксируются сервером: редактирование суммы или цены в запросе не даёт дополнительных денег. Повторные выдачи и повторные покупки запрещены.

### Надёжность и контроль
- Сервер хранит данные на диске с атомарной заменой файла.
- Изменения принимаются только в JSON, от разрешённого Origin и с действующим сеансом.
- Применяются ограничение размера запроса, лимит запросов и фиксированные серверные выплаты.
- Сведения о серверном кошельке не попадают в `localStorage`.
- Тесты проверяют попытку подмены локальных денег на 500 миллионов: **баланс подтверждённых ₡ должен остаться неизменным**.

## Как запустить серверный режим

В ZIP-релиз входит папка `server/`. Потребуется Node.js 20+.

1. Распакуй `zarya-os-2.2.1.zip`.
2. В папке игры выполни:

   ```bash
   node server/verified-server.cjs
   ```

3. Открой **http://127.0.0.1:8787/**.
4. Запусти в игре приложение «Проверка безопасности».

На Windows можно использовать `start-verified.cmd`.

## Что важно понимать

**Это не полноценный античит для всей игры.** На GitHub Pages невозможно запустить Node.js; онлайн-версия на GitHub Pages работает по-прежнему с локальными, изменяемыми деньгами. В ней новая вкладка покажет, что сервер не подключён. Серверную экономику нужно разворачивать отдельно, а затем постепенно переносить на неё все награды, покупки и профили.

В новой демонстрации ещё нет полноценных аккаунтов, восстановления профиля, постоянных многопользовательских идентичностей и защиты от автоматического решения опубликованных игровых загадок. По умолчанию сервер работает только локально. Открывать его всему интернету без дополнительного администрирования не рекомендуется.

**Прогресс версий 2.1 и 2.2 не сбрасывается.**
